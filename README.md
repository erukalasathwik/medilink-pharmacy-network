# MediLink – Medicine Availability & Pharmacy Finder

MediLink is a Java Full Stack web application that helps users search
for medicines and view their availability across pharmacies.

## Tech Stack

### Frontend
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Fetch API

### Backend
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- REST APIs
- Bean Validation

### Database
- MySQL

## Features

- Medicine search
- Pharmacy search
- Medicine availability tracking
- Available / Low Stock / Out of Stock status
- Pharmacy inventory management
- Customer medicine inquiries
- Admin statistics
- REST API integration
- Responsive UI

## Architecture

React.js
↓
REST APIs
↓
Spring Boot
↓
Spring Data JPA / Hibernate
↓
MySQL

## Project Structure

frontend/ – React frontend

backend/ – Spring Boot REST API

database.sql – Database setup

## Running Locally

### Backend

cd backend

mvn spring-boot:run

### Frontend

cd frontend

npm install

npm run dev
